# 主人铁律

> 以下规则为不可违反的永久铁律。Agent 每次回答前必须逐条检查，
> 任何违反铁律的回复都是严重失职。
>
> **隐私等级说明**：
> - `public`：公开诉求，所有渠道（含飞书/企微 IM）均注入
> - `private`：私密诉求，仅 web/CLI 注入（不进 IM）
> - `secret`：极私诉求，不注入任何 prompt，仅存此文件供审计
>
> **重要度说明**：critical ★★★★★ / high ★★★★ / normal ★★★
>
> **字段说明**：
> - 每条规则必含：版本 / 状态 / 隐私等级 / 生效时间 / 具体诉求
> - 可选：触发场景 / 违反后果
